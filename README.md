## ✨ Features & Visual Architecture

- **Sleek Dark Mode & Glassmorphism UI**: Uses deep slate aesthetics coupled with glowing cyan/neon blue accent tokens, backdrop filters, and refined soft shadow states.
- **Theme Toggler Engine**: Supports absolute live document attributes switching between `dark` and `light` profiles, retaining configurations automatically inside client `localStorage`.
- **Vanilla Typing Loop Engine**: Native JS-driven hero phrase cycler simulating realistic dynamic insertion and backspacing sequences.
- **Scroll Reveal System**: Intersection Observer API tracking element entries to seamlessly slide, fade, and zoom content cards on viewport intersection.
- **Responsive Sticky Layouts**: Implements an active top progress timeline tracker, responsive navigation states, custom CSS scrollbars, and full touch drawer controls.
- **Simulated Form Feedback**: Client-side event interception reproducing form input submission alerts natively without backend script reloads.

## 🚀 Free Hosting via GitHub Pages

Publish this portfolio live directly on your GitHub custom domain profile for absolutely zero cost:

1. **Initialize or Upload**: Push the repository contents (`index.html`, `style.css`, `script.js`) into a dedicated GitHub repository (e.g., `shlokkondekar02.github.io` or `Portfolio`).
2. **Access Repository Settings**: Navigate to the repository page on GitHub and click on the **Settings** tab.
3. **Locate Pages Configuration**: Scroll down the left sidebar and click on **Pages**.
4. **Select Branch Source**: Under the **Build and deployment** settings, select **Deploy from a branch**. Choose the `main` or `master` branch, set the directory to `/ (root)`, and hit **Save**.
5. **Live Verification**: GitHub Actions will compile your site immediately. Your live interactive URL will broadcast seamlessly in a few seconds!

## 📦 Bundling as a ZIP Archive for Academic Submission

To pack the workspace flawlessly for assignments, hackathon reviews, or direct transfer:

### On Windows OS
1. Open **File Explorer** and navigate to your main workspace folder (`d:\portfolio`).
2. Select all files (`index.html`, `style.css`, `script.js`, `README.md`).
3. **Right-click** the selected items, hover over **Send to**, and click **Compressed (zipped) folder**.
4. Rename the generated archive to `Shlok_Kondekar_Portfolio.zip` and upload to your respective submission endpoints.

### On macOS / Linux
1. Highlight your files inside the Finder / File Manager.
2. **Right-click** and select **Compress 4 Items**.
3. Rename `Archive.zip` as desired to finalize the clean independent bundle.
